## Status rules

- **Planned:** no complete implementation. A name, mockup, endpoint stub or roadmap entry is not delivery.
- **Partial:** some behavior exists, with the missing behavior identified below.
- **Preview verified:** UI/API/persistence and relevant negative tests have evidence against a named preview release.
- **External dependency:** the specific authorization/provider/operator choice is not available. Implement safe independent work; do not fabricate the dependency.
- **Production verified:** tested on the intended production domain and environment. No requirement currently has this status.

Do not report a completion percentage by counting differently sized requirements as equal. Update this map and evidence when behavior changes.

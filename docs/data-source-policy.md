# Authorized data-source policy

Use user-owned drafts, authorized exports or deliberately supplied content for which the user has rights. Public visibility is not blanket permission to scrape, republish or create datasets. Do not submit platform credentials, client secrets or unnecessary personal data.

Upwork, Fiverr and LinkedIn are not fetched or scraped. Reference URLs are stored only. Competitor text is a user-supplied, unverified snapshot. No CAPTCHA bypass, fake engagement/reviews or auto-posting is provided.

Future connectors require a permitted API, account authorization, scope/terms review, revocation/deletion lifecycle and provenance. The optional Workers AI adapter is implemented but disabled in the preview. Enabling it requires an operator usage decision and live evaluation; each run also requires explicit user consent to send the source snapshots and context. Source text is untrusted data, no execution/posting tools are exposed, and invalid or non-verbatim evidence citations are rejected. Valid citations do not prove that a generated draft is factually correct.

Policy references: [Upwork terms](https://www.upwork.com/legal), [Upwork automation guidance](https://support.upwork.com/hc/en-us/articles/43342677368467-Use-bots-and-other-automation-properly), [Fiverr terms](https://www.fiverr.com/legal-portal/legal-terms/terms-of-service). Recheck before integration; these links are not platform approval for Elancebot.
